                           Built a free Chrome extension to bulk delete YouTube playlists after dealing with account spam


Hi guys,

Recently my account got hacked, and the bot ended up creating over 1,750 fake playlists on my channel.

Since YouTube doesn't have an official "Select All & Delete" option for playlists, doing it manually was going to take forever. I ended up coding a lightweight Chrome extension to automate the cleanup for my own channel.

It worked great, so I decided to publish it in case anyone else gets hit with bot spam, wants to reset an old channel, or clean up clutter.

Features:

Deletes all playlists automatically in seconds.

Completely safe and lightweight (runs locally in your browser, no data saved/sent anywhere).
